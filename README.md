# DentCare 🦷

A full-stack healthcare appointment booking platform built during my internship — users can explore doctors, services, blogs, and pricing plans, create an account, book appointments, and track their status in real time.

🔗 **Live:** https://dentcare-website-production.up.railway.app/
🎥 **Demo Post:** https://www.linkedin.com/posts/ramsha-abid-b8b753312_reactjs-nodejs-mongodb-activity-7496457702420922368-f0Ah

## ✨ Features
- 👨‍⚕️ Browse doctors, services, blogs, and pricing plans
- 📅 Book appointments and track their status
- 🔐 JWT-based authentication with role-based access control (Admin / User)
- 🛠️ Full admin dashboard — manage appointments, users, subscribers, doctors, services, blogs, pricing, testimonials, comments, and homepage content
- 📧 Email notifications
- 🔔 Real-time-style notification system with unread counts on both user and admin dashboards

## 🛠️ Tech Stack
- **Frontend:** React.js, Vite, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Auth:** JWT
- **DevOps:** Docker, Railway
- **Other:** REST APIs

## 🚀 Getting Started

### Prerequisites
- Node.js
- MongoDB

### Installation
\`\`\`bash
git clone https://github.com/ramshaabid445-del/dentcare-website.git
cd dentcare-website

# Backend
cd backend
npm install
npm start

# Frontend
cd ../frontend
npm install
npm run dev
\`\`\`
